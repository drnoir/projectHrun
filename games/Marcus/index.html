Project Hrun

About The Game

Project Hrun is a top-down RPG game made by flixlstix all about exploring a small town and talking to the people in it.
The dialogue in the game is dynamic and can change depending on what you do, and there are collectibles which can be used to complete quests, and help townfolk.
The game uses a point-and-click control scheme which makes it easy to use!
